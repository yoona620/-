# -
AI 업무 및 거래처 관리 에이전트

## 연락톡 실행하기

Node.js와 Python 3가 설치된 환경에서 `npm start`를 실행하고
`http://localhost:3000`을 엽니다. 별도 패키지 설치는 필요하지 않습니다.
JavaScript 문법 검사는 `npm run check`로 실행합니다.

- `index.html`: 메뉴, 기본 화면 구조
- `styles.css`: 파란색·흰색 테마와 모바일 반응형 스타일
- `app.js`: 가상 거래처 데이터, 업무·연락 기록 관리, 로컬 데모 브리핑

거래처를 추가·수정하고 업무의 우선순위와 완료 상태를 관리할 수 있습니다.
연락 기록에 후속 조치와 다음 연락일을 함께 입력하면 업무가 자동으로 추가됩니다.
AI 브리핑은 우선순위와 일정에 기반한 로컬 데모로, 외부 AI 서비스를 호출하지 않습니다.

모든 데이터는 현재 탭의 메모리에만 있으며 새로고침하면 초기화됩니다.
실제 개인정보를 입력하지 마세요. 비밀 보관함 역시 데모 전용이며,
PBKDF2와 AES-GCM으로 메모를 암호화합니다. HTTPS 또는 localhost가 필요합니다.
다른 메뉴로 이동하거나 탭을 숨기거나 5분이 지나면 보관함이 잠깁니다.
저장하지 않은 메모 수정은 잠금 시 사라지며 비밀번호 복구 기능은 없습니다.
